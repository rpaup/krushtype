# krushtype ⌨️

**krushtype** — это современный десктопный клавиатурный тренажер (аналог MonkeyType), разработанный на базе WPF (Windows Presentation Foundation) и C#. Приложение предназначено для проверки и улучшения скорости и точности печати, а также ведения подробной статистики ваших результатов.

## 🚀 Основные возможности

* **Система профилей:** Регистрация, авторизация и сохранение истории прогресса как для локальных пользователей, так и в оффлайн-режиме (без аккаунта).
* **Глубокая статистика:** Отслеживание ключевых метрик — WPM (слов в минуту), Raw WPM, Accuracy (точность) и Consistency (стабильность).
* **Множество режимов и языков:** Возможность включения чисел, пунктуации, а также поддержка тестирования на более чем 60 языках (русский, английский, испанский, японский, китайский и многие другие).
* **Визуализация прогресса:** Интерактивные графики для отслеживания динамики развития во времени.
* **Темы оформления:** Поддержка светлой и темной темы интерфейса для комфортной печати в любых условиях.
* **Экспорт данных:** Возможность выгрузить свои результаты в формат `.csv` для дальнейшего анализа.
* **Portable-сборка:** Приложение компилируется в единый независимый `.exe` файл (благодаря `Costura.Fody`), что делает его максимально портативным и удобным.

## 🛠 Технологии и архитектура

Проект построен с использованием современных подходов и паттерна **MVVM (Model-View-ViewModel)**.

* **Платформа:** .NET Framework 4.8 / C#
* **UI-фреймворк:** WPF (Windows Presentation Foundation)
* **Библиотеки:** 
  * `Newtonsoft.Json` — работа с JSON-файлами (конфигурации, профили, локализация).
  * `OxyPlot.Wpf` — построение графиков статистики.
  * `Costura.Fody` — упаковка всех зависимостей (DLL) внутрь одного исполняемого файла.
  * `Ookii.Dialogs.Wpf` — нативные диалоговые окна Windows (например, для выбора пути экспорта).

## 📁 Структура проекта

* `Core/Models/` — Бизнес-логика, модели аккаунтов пользователей и результатов тестов.
* `Core/ViewModels/` — Логика представления (VM), связывающая интерфейс с моделями (TypingVM, AccountVM и др.).
* `Core/Utilities/` — Вспомогательные классы (работа с файлами JSON/CSV, генерация графиков, конвертеры, RelayCommand для MVVM).
* `UI/Views/` — XAML страницы и окна приложения (MainWindow, Typing, Account, Login, TestResults и др.).
* `UI/Styles/` — Стили для элементов управления и цветовые схемы (Light / Dark themes).
* `Assets/` — Шрифты, иконки и база слов для тестов (файлы `.json` для каждого языка).

## 📥 Как запустить проект

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/rpaup/krushtype.git
   ```
2. Откройте решение `krushtype.sln` в **Visual Studio**.
3. Убедитесь, что у вас установлены инструменты для разработки классических приложений .NET (WPF).
4. Восстановите NuGet пакеты (обычно Visual Studio делает это автоматически перед сборкой).
5. Нажмите `F5` или кнопку "Пуск" (Start), чтобы скомпилировать и запустить приложение.
